RANCHÃO BEBIDAS — ATUALIZAÇÃO INCREMENTAL 1.2.48

ESTE PACOTE CONTÉM SOMENTE OS ARQUIVOS ALTERADOS.

Não existe SQL novo nesta atualização.

COMO ATUALIZAR

1. Envie todos os arquivos e a pasta ranchao-bebidas-desktop para a raiz do
   repositório no GitHub.
2. Confirme a substituição dos arquivos existentes, preservando a estrutura
   das pastas.
3. Não apague as demais pastas e arquivos que já estão no repositório.
4. Abra Actions > Publicar atualização do aplicativo > Run workflow.
5. Informe a versão 1.2.48 e confirme.

ALTERAÇÕES

- Ao editar uma conta a pagar, a classificação financeira agora é escolhida
  em uma janela própria de pesquisa.
- A pesquisa aceita código ou qualquer parte da descrição e mostra todas as
  classificações disponíveis.
- Também é possível navegar pelas opções usando as setas e confirmar com Enter.
- O aviso de contas sem classificação deixou de usar a caixa do Windows e
  passou a usar uma janela no padrão visual do sistema.
- Cada ocorrência de entrega ganhou um botão próprio para gerar PDF.
- O PDF individual mostra dados da entrega, fornecedor, pedido, nota fiscal,
  descrição, produtos, quantidades, custos, valor afetado, providência,
  responsável, prazo, status, solução e valor recuperado.
